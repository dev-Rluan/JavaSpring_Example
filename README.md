# JavaSpring_Example

자바와 Spring Boot 예제를 위한 프로젝트입니다. 현재 `demo/`에는 Spring Boot 기본 애플리케이션과 Gradle 설정이 있습니다.

- 구성: Java 17, Spring Boot 3.1.2, Web, Thymeleaf, JPA, H2
- 코드: [demo/src](demo/src)
- 빌드 설정: [demo/build.gradle](demo/build.gradle)

## 실행

JDK 17을 준비한 뒤 `demo/`에서 실행합니다.

```bash
cd demo
./gradlew bootRun
```

Windows에서는 `gradlew.bat bootRun`을 사용합니다. 개별 예제 기능은 소스가 추가되는 범위에 맞춰 기록합니다.
